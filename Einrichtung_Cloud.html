Einrichtung Cloud-Sync

Makler-Prozess 2.1 · Nextcloud oder OneDrive/SharePoint vorbereiten · ca. 10 Minuten

Nextcloud
Benötigt: Nextcloud-Adresse, Benutzername, App-Passwort, gemeinsamer Ordner.
OneDrive / SharePoint
Benötigt: einmalige App-Registrierung im Microsoft-365-Konto des Büros (Anwendungs-ID), Zielordner.

1. Nextcloud

App-Passwort erstellen (je Gerät empfohlen)

  1. Nextcloud im Browser öffnen und anmelden.
  2. Oben rechts auf das Profilbild → Persönliche Einstellungen → Sicherheit.
  3. Unten bei Geräte & Sitzungen einen Namen eingeben, z. B. Makler-Prozess PC Büro → Neues App-Passwort erstellen.
  4. Angezeigtes Passwort kopieren und im Einrichtungs-Assistenten der App eintragen. Es wird nur einmal angezeigt.

Ein App-Passwort lässt sich dort jederzeit einzeln widerrufen (z. B. bei Verlust des Tablets), ohne das Hauptpasswort zu ändern.

2. OneDrive / SharePoint (Microsoft 365)

Damit die App auf OneDrive zugreifen darf, braucht das Büro einmalig eine App-Registrierung. Das erledigt der Microsoft-365-Administrator.

App-Registrierung anlegen

  1. entra.microsoft.com öffnen → Anwendungen → App-Registrierungen → Neue Registrierung.
  2. Name: Makler-Prozess · Unterstützte Kontotypen: Nur Konten in diesem Organisationsverzeichnis · Umleitungs-URI leer lassen → Registrieren.
  3. Auf der Übersichtsseite notieren: Anwendungs-ID (Client) und Verzeichnis-ID (Mandant).
  4. Authentifizierung → Erweiterte Einstellungen: Öffentliche Clientflows zulassen auf Ja stellen → Speichern. (Englisch: Allow public client flows.) Nötig für die Anmeldung per Code.
  5. API-Berechtigungen → Berechtigung hinzufügen → Microsoft Graph → Delegierte Berechtigungen: Files.ReadWrite.All, Sites.ReadWrite.All, User.Read, offline_access → hinzufügen.
  6. Administratorzustimmung für … erteilen klicken.

Die Bezeichnungen im Microsoft-Portal ändern sich gelegentlich leicht. Die Einstellung für öffentliche Clientflows liegt je nach Ansicht unter Authentifizierung → Einstellungen bzw. Erweiterte Einstellungen.

3. Büro einrichten und Geräte verbinden

  1. Erstes Gerät (mit den bisherigen Daten): Einstellungen → Daten & Sicherung → Cloud-Sync einrichten → Anbieter → Anmeldung → Büro-Passwort (mind. 10 Zeichen) → Hochladen.
  2. Danach Wiederherstellungsschlüssel (Einstellungen → Daten & Sicherung) ausdrucken bzw. im Passwort-Manager ablegen.
  3. Weitere Geräte: beim ersten Start „Bestehendem Büro (Cloud) beitreten“ → gleicher Ordner, gleiches Büro-Passwort → anschließend den eigenen Mitarbeiter wählen.

Datenschutz: Mieter- und Bonitätsdaten liegen verschlüsselt in der Cloud, Dokumente (Protokolle, Fotos, Verträge) jedoch lesbar im Ordner dateien. Mit dem Cloud-Anbieter sollte ein Auftragsverarbeitungsvertrag (AVV) bestehen und der Speicherort in der EU liegen.

4. Tablet (Android-App / Browser-App)

Das Tablet tritt wie jedes weitere Gerät dem Büro bei. Installation, GitHub-Bau sowie die Zusatzeinstellungen für die Browser-App (Nextcloud-CORS-Freigabe, OneDrive-Umleitungs-URI für „Single-Page-Anwendung“) stehen in Einrichtung_Tablet.html. Die Android-App braucht keine Zusatzeinstellungen.

5. Was liegt wo in der Cloud?

OrdnerInhaltLesbar?
office.jsonKennung des Büros und Prüfwert für das Passwortja, enthält keine Daten
sync/<Gerät>/Änderungspakete je Gerätnein – AES-256 verschlüsselt
snapshot/Gesamtstand zum schnellen Beitreten neuer Gerätenein – verschlüsselt
devices/Gerätename, Version, letzter Abgleichja
dateien/Objekte/…Protokolle, Fotos, Anhänge, PDFs – gleiche Struktur wie lokalja

Bitte in der Cloud nichts in sync, snapshot oder office.json ändern oder löschen. Dokumente im Ordner dateien können gelesen und heruntergeladen werden.
