2. GitHub einrichten (einmalig, am PC)

Benötigt: die Dateien MaklerProzess_v2.1.0_Repo.zip und MaklerProzess_Android-Signierschluessel.zip.

1Konto und Repository anlegen

  1. github.com öffnen → anmelden bzw. Sign up (kostenloses Konto genügt).
  2. Oben rechts + → New repository.
  3. Repository name: makler-prozess · Sichtbarkeit Public · Add a README nicht anhaken → Create repository.

Warum „Public“? Die kostenlose Veröffentlichung der Browser-App (GitHub Pages) setzt ein öffentliches Repository voraus. Sichtbar ist nur der Programmcode – keine Daten, keine Passwörter, kein Signierschlüssel (der liegt verschlüsselt in den Secrets). Wer das nicht möchte: Private wählen und GitHub Pro nutzen, oder auf die Browser-App verzichten (die APK gibt es dann unter Actions → Artifacts).

2Signierschlüssel als Secrets hinterlegen

Damit jede neue APK über die alte installiert werden kann, wird sie immer mit demselben Schlüssel signiert.

  1. MaklerProzess_Android-Signierschluessel.zip entpacken.
  2. Im Repository: Settings → links Secrets and variables → Actions → New repository secret.
  3. Name ANDROID_KEYSTORE_B64 · Secret: kompletten Inhalt der Datei ANDROID_KEYSTORE_B64.txt einfügen → Add secret.
  4. Noch einmal New repository secret: Name ANDROID_KEYSTORE_PASSWORD · Secret: Inhalt von ANDROID_KEYSTORE_PASSWORD.txt → Add secret.

Das Schlüssel-ZIP sicher aufbewahren (Passwort-Manager / Tresor), nicht ins Repository hochladen. Geht der Schlüssel verloren, lässt sich die App nur nach Deinstallation aktualisieren.

3GitHub Pages einschalten

  1. Settings → links Pages.
  2. Unter Build and deployment → Source: GitHub Actions wählen. (Kein weiterer Knopf nötig.)

4Code hochladen (zwei Durchgänge, je max. 100 Dateien)

  1. MaklerProzess_v2.1.0_Repo.zip entpacken → Ordner makler-prozess öffnen.
  2. Im Repository Code → Link uploading an existing file (bzw. später Add file → Upload files).
  3. Durchgang A: nur den Ordner android in das Browserfenster ziehen → warten, bis alle Dateien gelistet sind → unten Commit changes.
  4. Durchgang B: Add file → Upload files → alle übrigen Dateien und Ordner markieren (inkl. .github, .gitignore) und hineinziehen → Commit changes.

Erst mit Durchgang B kommt die Bauanleitung (.github/workflows) dazu – der Bau startet dann automatisch mit vollständigem Code. Unter Windows sind Ordner mit Punkt (.github) normal sichtbar. Alternativ geht das Hochladen bequem mit GitHub Desktop.

5Bau abwarten

  1. Reiter Actions → Lauf „Tablet-App bauen“ (gelber Punkt = läuft, ca. 6–10 Minuten).
  2. Grüner Haken → fertig. Unter dem Lauf: Artifacts → MaklerProzess-Android-APK und oben die Adresse der Browser-App.
Ergebnis

Android-App: https://KONTO.github.io/makler-prozess/MaklerProzess.apk

3. Tablet installieren

Android-App
  1. Am Tablet in Chrome https://KONTO.github.io/makler-prozess/MaklerProzess.apk öffnen → herunterladen.
  2. Download antippen → Hinweis „Unbekannte Apps“ → Einstellungen → Dieser Quelle vertrauen → zurück → Installieren.
  3. Meldet Google Play Protect „unbekannte App“: Weitere Details → Trotzdem installieren.
  4. App Makler-Prozess öffnen.
Browser-App
  1. Am Tablet in Chrome https://KONTO.github.io/makler-prozess/ öffnen.
  2. Menü ⋮ → App installieren (oder „Zum Startbildschirm hinzufügen“).
  3. Ab jetzt über das Symbol starten – läuft wie eine App und auch offline.

Für Nextcloud/OneDrive vorher Kapitel 4 bzw. 5 erledigen.

Erster Start

  1. Bestehendem Büro beitreten wählen (das Büro wird am PC eingerichtet: Einstellungen → Daten & Sicherung → Cloud-Sync einrichten).
  2. Anbieter, Zugangsdaten und Cloud-Ordner wie am PC eintragen. Für Nextcloud ein eigenes App-Passwort für das Tablet erstellen.
  3. Büro-Passwort (oder Wiederherstellungsschlüssel) eingeben, Gerätename z. B. „Tablet Außendienst“.
  4. Mitarbeiter antippen → PIN festlegen (4–6 Ziffern, zweimal). Hat der Mitarbeiter am PC schon eine PIN, gilt diese.

Zum Ausprobieren ohne Cloud: „Ausprobieren mit Beispieldaten“. Später unter Gerät → Gerät zurücksetzen entfernen und dem Büro beitreten.

4. Nextcloud für die Browser-App freigeben (CORS)

Ein Browser darf nur auf fremde Server zugreifen, wenn diese es erlauben. Die Android-App braucht das nicht. Für die Browser-App muss die Nextcloud Zugriffe von https://KONTO.github.io erlauben – nur für die Dateischnittstelle /remote.php/dav/.

Nur die eigene Herkunft eintragen (nie *). Bei gehosteter Nextcloud (Anbieter) ist das meist nicht einstellbar → Android-App verwenden.

nginx (eigener Reverse-Proxy vor der Nextcloud)

# im server { … }-Block der Nextcloud ergänzen – vor dem allgemeinen location /
location ^~ /remote.php/dav/ {
    if ($request_method = OPTIONS) {
        add_header Access-Control-Allow-Origin  "https://KONTO.github.io" always;
        add_header Access-Control-Allow-Methods "GET, PUT, DELETE, PROPFIND, MKCOL, MOVE, COPY, OPTIONS" always;
        add_header Access-Control-Allow-Headers "Authorization, Content-Type, Depth, Destination, Overwrite" always;
        add_header Access-Control-Max-Age 3600 always;
        return 204;
    }
    proxy_hide_header Access-Control-Allow-Origin;
    add_header Access-Control-Allow-Origin  "https://KONTO.github.io" always;
    add_header Access-Control-Expose-Headers "ETag, DAV" always;
    # die proxy_pass- und proxy_set_header-Zeilen aus dem bestehenden location / hierher kopieren, z. B.:
    proxy_pass http://127.0.0.1:11000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
    client_max_body_size 1G;
}

Nginx Proxy Manager (häufig auf NAS-Systemen): Proxy-Host der Nextcloud → Advanced → Custom Nginx Configuration: obigen Block einfügen und proxy_pass durch proxy_pass $forward_scheme://$server:$port; ersetzen.

Apache (Nextcloud direkt auf Apache)

# in der VirtualHost-Konfiguration (benötigt mod_headers und mod_rewrite)
<LocationMatch "^/remote.php/dav/">
    Header always set Access-Control-Allow-Origin  "https://KONTO.github.io"
    Header always set Access-Control-Allow-Methods "GET, PUT, DELETE, PROPFIND, MKCOL, MOVE, COPY, OPTIONS"
    Header always set Access-Control-Allow-Headers "Authorization, Content-Type, Depth, Destination, Overwrite"
    Header always set Access-Control-Expose-Headers "ETag, DAV"
</LocationMatch>
RewriteEngine On
RewriteCond %{REQUEST_METHOD} OPTIONS
RewriteRule ^/?remote\.php/dav/ - [R=204,L]

Prüfen: Browser-App öffnen → „Bestehendem Büro beitreten“ → Nextcloud. Erscheint „Zugriff aus dem Browser (CORS) nicht freigegeben“, greift die Freigabe noch nicht (Server neu laden, Adresse/Herkunft prüfen). Die Nextcloud muss per HTTPS erreichbar sein.

5. OneDrive für die Browser-App (App-Registrierung ergänzen)

Die bestehende App-Registrierung (siehe Einrichtung_Cloud.html) bekommt eine zusätzliche Plattform. Die Android-App braucht das nicht – sie meldet sich wie der PC per Code an.

  1. entra.microsoft.com → Anwendungen → App-Registrierungen → Makler-Prozess.
  2. Authentifizierung → Plattform hinzufügen → Single-Page-Anwendung.
  3. Umleitungs-URI: https://KONTO.github.io/makler-prozess/auth.html (exakt so, wie sie im Assistenten der Browser-App angezeigt wird) → Konfigurieren.

Microsoft begrenzt Anmeldungen von Browser-Apps auf 24 Stunden. Zeigt die Leiste „Cloud-Anmeldung nötig“, darauf tippen – das Anmeldefenster schließt sich meist sofort wieder. Offline erfasste Änderungen bleiben bis dahin erhalten.

Sicherheit & Datenschutz

  • Büro-Daten liegen am Tablet im App-Speicher (Android-verschlüsselt), in der Cloud AES-256-verschlüsselt; Dokumente lesbar im Cloud-Ordner dateien (wie am PC).
  • Zugangsdaten (App-Passwort, Microsoft-Anmeldung, Büro-Schlüssel) werden am Tablet mit einem nicht exportierbaren Geräteschlüssel verschlüsselt gespeichert.
  • PIN-Pflicht, automatische Sperre nach 10 Minuten. Android-Sicherung der App-Daten ist abgeschaltet.
  • Tablet verloren: in Nextcloud (Einstellungen → Sicherheit) das App-Passwort des Tablets widerrufen bzw. im Microsoft-Konto die Sitzungen abmelden. Bei Verdacht zusätzlich das Büro-Passwort neu vergeben lassen (neues Büro anlegen).
  • GitHub hostet nur den Programmcode; es werden keine Büro-Daten an GitHub übertragen.
